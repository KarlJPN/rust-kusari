# rust-kusari

Rustを「最小単位から、前の理解なしでは次に進めない順番」で学ぶためのハンズオンプロジェクト。

最終成果物は、自作のミニスクリプト言語と、それを使った実用CLIツール。

## このリポジトリについて

これは完成品のショーケースではなく、**学習の過程そのもの**を記録したリポジトリです。

- 各ステップのコミットが、学習の進行順にそのまま残っています
- `docs/learning-log/` に、各ステップで何を学び、どこで詰まったかの記録があります
- `docs/plan.md` に、全体の学習計画があります

## 学習の設計思想

このプロジェクトは、Nand2Tetris（コンピュータシステムの理論と実装）の哲学に影響を受けています。

- 前のステップを理解していないと、次のステップが物理的に書けない
- 新しい概念は「なぜ今必要か」が明確になってから導入する
- 便利でも、まだ必要ない概念は先取りしない

## フェーズ構成

**フェーズ1: ミニ言語のコアを作る**（15ステップ）

文字列入力 → 字句解析 → 構文解析 → 評価 → 変数 → 制御構文 → REPL

**フェーズ2: 実用CLIを作る**（5ステップ）

CLI引数 → ファイル読み込み → 実データ処理 → エラー改善 → リファクタリング

## 学べるRustの概念

このプロジェクトを通じて、以下の概念を必然的な順序で学びます。

`String` / `&str`, `Vec`, `HashMap`, `struct`, `impl`, `enum`, `match`, 所有権と借用, `Result` / `Option` / `?`, カスタムエラー型, `trait`（Display, Error）, モジュール分割, テスト, CLI, ファイルI/O

## 著者

教員として情報Iを教えながら、個人開発者としての独立を目指してRustを学んでいます。

## 自分でやってみたい人へ

このリポジトリのmainブランチには、著者の学習記録がそのまま残っています。
まっさらな状態から始めたい場合は、以下のようにしてください。

git clone https://github.com/KarlJPN/rust-kusari.git
cd rust-kusari
git checkout v0-start
