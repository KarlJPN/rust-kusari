# Step 2: 文字列・スライス・位置追跡

## 学んだ概念

### 1. String と &str の違い
- `String` は自分が所有するノート。中身を書き換えられる
- `&str` はそのノートを見せてもらうだけ（指差し）。借りているだけ
- `&` をつけると String を &str として渡せる（所有権を渡さず見せるだけ）

### 2. & で借りると何回でも使える
- `&` で渡すと所有権が移動しないので、同じ変数を何回でも使い回せる
- 関数の引数を `&str` で受け取る理由: 読むだけなら所有権をもらう必要がない

```rust
fn shout(word: &str) {
    println!("{}!!!", word);
}

fn main() {
    let name = String::from("Rust");
    shout(&name);  // 見せるだけ
    shout(&name);  // まだ手元にあるからもう一度見せられる
}
```

### 3. for と chars() で1文字ずつ読む
- `input.chars()` が文字列を「1文字ずつ取り出せる状態」に準備する
- `for ... in` がそこから1つずつ取り出して繰り返す
- この2つで1セット

```rust
for c in input.chars() {
    println!("{}", c);
}
```

### 4. if ... else ... で条件分岐
- 「もし〜なら、こうする。そうでなければ、こうする」
- Python の if/else とほぼ同じ。違いは条件にカッコ不要、`{}` が必須

### 5. \n は改行文字
- 文字列の中で `\n` と書くと、そこで改行される
- `"ab\ncd"` → 1行目 "ab"、2行目 "cd"

### 6. 位置追跡（line と column）
- 文字を読みながら「今何行目の何文字目か」を数える
- 改行 `\n` に当たったら → 行を増やして列を1に戻す
- それ以外なら → 列を1増やす
- 将来エラーメッセージで「3行目の5文字目がおかしい」と伝えるために必要

```rust
let mut line = 1;
let mut column = 1;

for c in input.chars() {
    println!("({}, {}): '{}'", line, column, c);

    if c == '\n' {
        line = line + 1;
        column = 1;
    } else {
        column = column + 1;
    }
}
```

## なぜこれらが必要だったか
- ミニ言語インタプリタは、ユーザーが書いたコードを「文字列として受け取る」ところから始まる
- 文字列を1文字ずつ読み、どこを読んでいるか追跡できなければ、字句解析（次のステップ）に進めない
- エラー位置情報を後付けすると設計変更が大きくなるため、今のうちに仕込んでおく
