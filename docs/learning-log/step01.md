# Step 1: 基本型・変数・関数

## 学んだ概念

### 1. 型とは何か
- プログラミングにおける「型」とは、データの種類のこと
- 型によって「何を入れられるか」「何ができるか」が決まる

### 2. i64 型
- 小数点のない数値（整数）を入れる型
- 「64ビット符号付き整数」= 非常に大きな数からマイナスの数まで扱える
- 例: `let x: i64 = 42;`

### 3. bool 型
- true（はい）と false（いいえ）の2つの値しかない型
- 「判断結果を入れる箱」のようなもの
- 比較演算子（`>=`, `==`, `<` など）の結果が bool になる
- 例: `let ok: bool = true;`

### 4. 変数束縛（let / let mut）
- `let x = 10;` → 不変の変数（後から変えられない）
- `let mut x = 10;` → 可変の変数（後から変えられる）
- Rust では「変数に値を束縛する」と表現する

### 5. 関数（fn）
- 「引数を受け取って、処理をして、値を返すもの」
- 同じ処理を使い回せる、名前で意味を伝えられる
- 自動販売機に例えると：お金（引数）を入れて → 内部で処理して → 飲み物（戻り値）が出てくる

```rust
fn multiply(a: i64, b: i64) -> i64 {
    a * b   // セミコロンなしの最後の式が戻り値になる
}
```

- 引数には型を指定する（`a: i64`）
- `->` の後に戻り値の型を書く
- 関数の最後の式にセミコロンをつけないと、その値が自動的に返される

### 6. 比較演算子と bool の関係
- `>=` などの比較演算子が2つの値を比較する
- その結果として bool 型の値（true / false）が生まれる
- bool が判定するのではなく、比較演算子が判定して結果を bool で返す

```rust
fn is_passing(score: i64) -> bool {
    score >= 60  // 比較の結果がそのまま bool として返される
}
```

## なぜこれらが必要だったか
- ミニ言語インタプリタでは、数値（i64）と真偽値（bool）が最も基本的なデータ型
- 変数と関数がなければ、どんなプログラムも書けない
- これらは全ての土台になる概念
